## 必改纠错

- F+7：游戏 → 工具箱（电子木鱼 / CW）
- 收音机：补 MENU 存台/删台、F+3 切 MR/VFO、频段切换等
- 保存信道：菜单存信道；**信道模式下改参后必须再存信道才持久生效**（用户特别强调）
- FAQ #14 频段锁定表：对齐当前菜单（含 CA / GMRS / PMR 等）
- 校准地址：保持 v5+ `0xB000` / 更早 `0x1E00`，SPI `0x010000`；按现固件与网页工具描述
- MDC：按现固件；Yan ID 仅注明规划中
